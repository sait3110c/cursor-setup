# 03 Ask と Agent

所要: 20分  
ゴール: 説明させてから、ボタンを1箇所直し、diff を確認する

題材は [`practice/`](../practice/) です。公式の流れと同じです。説明 → 小さい変更 → diff。[Quickstart](https://cursor.com/docs/get-started/quickstart)

画面上のモード名はバージョンで違うことがあります。読めない操作をするモードが **Ask**、編集してよいモードが **Agent** だと考えてください。

## 1. Ask で聞く

Ask（読み取り中心）に切り替え、次をそのまま送ってください。

```
practice/ の入口ファイルを教えてください。
送信ボタンが動かない理由も、ファイルと箇所を指して説明してください。
まだコードは変えないでください。
```

期待する答えの要点:

- 入口は `practice/index.html`
- ボタンの id は `submit-btn` なのに、`app.js` が `#sendBtn` を探している

## 2. Agent で直す

Agent（編集してよいモード）に切り替え、次を送ってください。**この修正だけ**頼んでください。

```
practice/ の送信ボタンが動くようにしてください。
原因はセレクタの不一致だけです。
関係ないリファクタや見た目の変更はしないでください。
```

## 3. diff を確認する

Agent が示した差分を読んでください。

- `app.js` の `#sendBtn` が `#submit-btn` になっていればよい
- よければ Accept（適用）する
- 範囲が広すぎる、または関係ないファイルまで触っていたら Reject（却下）し、上の文をもう一度送る

適用したら `practice/index.html` をブラウザで開き、名前とメールを入れて送信してください。何かしらのメッセージが出れば成功です。文言が英語のままで構いません。

今日は使いません。
