# 02 初回起動

所要: 10分  
ゴール: このリポジトリを開き、Agent に話しかけられる

## フォルダを開く

Cursor で **このリポジトリの一番上** を開きます。`README.md` と `practice/` が並んでいれば正解です。

- macOS: **File → Open Folder…**（`Cmd+O`）
- Windows: **File → Open Folder…**（`Ctrl+K` のあと `Ctrl+O` など。メニューから開いてよい）

`practice/` だけを開かないでください。あとでファイルを指すとき、リポジトリ直下が基準になります。

## 画面の3領域

覚えるのはこれだけです。

| 場所 | 役割 |
|---|---|
| 左 | ファイル一覧 |
| 中央 | エディタ |
| 右（または下） | Agent。コードの説明・編集を頼む場所 |

Agent が閉じていたら:

- macOS: `Cmd+I` または `Cmd+L`
- Windows: `Ctrl+I` または `Ctrl+L`

ショートカットが違っても、チャット / Agent 用のパネルを開ければ十分です。

## モデル

Agent 入力欄の近くに、使うモデルの名前があります。開催時点の推奨は進行役が口頭で伝えます。

迷ったら、一覧の先頭付近にある標準的なモデルのままで進めてください。

## 今日触らなくてよいもの

- 拡張機能の追加
- テーマやフォントの変更（見にくければ変えてよい）
- Skills / MCP の設定
- 自分の仕事用リポジトリ

確認できたら [practice/index.html](../practice/index.html) をエディタで開いておいてください。ブラウザで開いても構いません。送信ボタンは、この時点では動きません。
