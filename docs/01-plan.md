# 01 プラン

所要: 10分  
ゴール: 料金ページの違いが分かり、当日配布のクレジットで Pro を付ける

金額やボタン名は変わります。**画面の表示を正**としてください。契約にはカード登録が必要です。

## すでに Pro 以上の人

Cursor または [Billing dashboard](https://cursor.com/dashboard/billing) でプランが Pro / Pro+ / Ultra / Teams など有料なら、この章の適用は飛ばして [02 初回起動](02-first-launch.md) へ進んでください。

## 1. 料金ページを見る

ブラウザで [cursor.com/pricing](https://cursor.com/pricing) を開きます。今日覚える差は次だけです。

| プラン | 今日の位置づけ |
|---|---|
| Hobby | 無料。Agent の回数などに制限がある |
| **Pro** | このハンズオンの推奨。クレジット適用後の到達点 |
| Pro+ / Ultra / Teams | あとで選ぶ。今日は触らない |

購入・契約は [cursor.com](https://cursor.com/pricing) だけです。

## 2. 当日配布の案内に従う

進行役が、リンクまたはコードを配る場合があります。案内があれば、そのとおりに進めてください。

- 契約にはカード登録が必要です
- 画面の入力欄名はバージョンで違うことがあります。進行役の口頭を優先する
- 迷ったら手を止めて声をかける

管理画面の入口は [cursor.com/dashboard/billing](https://cursor.com/dashboard/billing) です。進行役が別の URL を出したら、そちらを開きます。

## 3. 付いたか確認する

次のどれかで、プラン名が **Pro**（またはそれ以上）になっていれば十分です。

- [Billing dashboard](https://cursor.com/dashboard/billing) の現在のプラン
- Cursor の Settings にあるアカウント / Billing

反映されないときは Cursor を一度終了して起動し直してください。まだ Hobby のままなら進行役に声をかけてください。
