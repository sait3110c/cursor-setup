# 困ったとき

本編に戻る: [README](../../README.md)

## インストーラが落ちてこない / 途中で止まる

- URL が [cursor.com/downloads](https://cursor.com/downloads) か確認する
- 会場 Wi-Fi を一度切り、テザリングで取り直す
- ブラウザを変えるか、ダウンロードをやり直す

進行役に声をかければ、ヘルプに入ります。

## 開こうとすると警告が出る（macOS / Windows）

署名や提供元の警告です。公式 downloads から取ったファイルなら、OS の案内に従って開いて構いません。

- macOS: 「開発元を確認できない」→ システム設定のプライバシーとセキュリティから許可するか、Control キーを押しながら開く
- Windows: SmartScreen が出たら「詳細情報」から実行する

第三者のサイトから取ったファイルでは進めないでください。取り直します。

## サインインできない

- ブラウザのポップアップや OS の許可ダイアログを確認する
- 会社ネットワークや VPN を切って再試行する
- 公式サイトのアカウントで Web にログインできるか確認する

まだダメなら進行役に声をかけてください。資料の閲覧だけ先に進めて構いません。

## プランが付かない / まだ Hobby のまま

- 進行役が案内を配っている場合は、もう一度辿る
- [Billing dashboard](https://cursor.com/dashboard/billing) をブラウザで開き直す
- Cursor を完全に終了して起動し直す
- カード登録を求められたら、公式の決済画面で進めてよい。迷ったら進行役に聞く

## モデルが一覧に出ない / Agent が使えない

- サインインし直す
- Cursor を再起動する
- プランが Hobby のままだと制限されることがある。`01` の確認をもう一度やる
- 進行役が案内するモデルに切り替える

## Agent がファイルを開かない / 的外れな場所を触る

- 開いているフォルダがリポジトリ直下か確認する（`practice/` だけ開いていないか）
- プロンプトに `practice/app.js` のようにパスを書く
- 会話を新規にして、章のコピー用プロンプトをもう一度送る

## フォルダを間違えて開いた

**File → Open Folder…** で、`README.md` が見える階層を開き直してください。

## Windows でスクリプトやプレビューが動かない

この演習は `index.html` をブラウザで開ければ十分です。ターミナルは必須ではありません。

PowerShell の実行ポリシーで npm などが止まる場合も、今日は無視してブラウザ確認に進んでください。

## 送信ボタンが直ったのに何も表示されない

- `index.html` を保存したあと、ブラウザを再読み込みする
- ブラウザの開発者ツールでエラーが出ていないか見る
- `app.js` のセレクタが `#submit-btn` になっているか見る
