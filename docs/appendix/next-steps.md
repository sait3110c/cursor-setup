# 次の一歩

本編（60分）ではやっていません。仕事リポジトリで使うときの地図です。

| 機能 | 何のためのものか | 公式 |
|---|---|---|
| Project Rules | 毎回言う約束事（日本語で返す、この構成を崩さない、など）を `.cursor/rules/` に書いておく | [Rules](https://cursor.com/docs/rules) |
| Plan | 大きめの変更の前に、方針と手順を固めてから実装する | [Quickstart](https://cursor.com/docs/get-started/quickstart) |
| Skills | 「リリースの手順」のような手順書を、必要なときだけ読ませる | [Skills](https://cursor.com/docs/skills) |
| MCP | ブラウザ、Issue、社内 API など、エディタ外の道具を Agent に渡す | [MCP](https://cursor.com/docs/mcp) |
| Team Rules | チームプランで、メンバー共通の Rule を配る | [Rules](https://cursor.com/docs/rules) |

最初に足すなら、短い Project Rule が扱いやすいです。Skills と MCP は、同じ指示を毎回書いていると気づいてからで十分です。
