# 00 ダウンロード

所要: 15分  
ゴール: 公式サイトから Cursor を入れ、起動してサインインする

資料はこの章のあいだ、ブラウザで開いたままで構いません。

## すでに入っている人

Cursor が起動し、サインインできていれば、この章のインストールは飛ばしてください。サインインだけ済ませて [01 プラン](01-plan.md) へ進みます。

## 1. 公式から入れる

ブラウザで [cursor.com/downloads](https://cursor.com/downloads) を開きます。転売サイトや「無料ダウンロード」と謳う第三者は使いません。

1. 自分の OS 用のインストーラを取る
2. 案内に従って入れる

| OS | 目安 |
|---|---|
| macOS | 12 以降。`.dmg` を開き、アプリケーションへ入れる |
| Windows | 10 以降。`.exe` を実行する |
| Linux | 公式 [Quickstart](https://cursor.com/docs/get-started/quickstart) の手順に従う |

インストーラが落ちない、警告が出る、起動しないときは [困ったとき](appendix/troubleshooting.md) を見てください。

## 2. 起動してサインインする

1. Cursor を起動する
2. 画面の案内に従ってアカウントを作るか、既存アカウントで入る

サインインできないときも [困ったとき](appendix/troubleshooting.md) です。資料の閲覧はブラウザで続けられます。

## 3. この資料を手元に置く

Cursor が入ってからで構いません。どれか1つ。

```bash
git clone <このリポジトリの URL>
```

Git を使わない場合は、リポジトリの ZIP を展開してください。URL は進行役が案内します。

展開先のフォルダ名は何でもよいです。次の章のあとに、**リポジトリの一番上**（`README.md` が見える階層）を Cursor で開きます。

## 完了チェック

- [ ] Cursor が起動する
- [ ] サインインできている
- [ ] このリポジトリが手元にある（clone または ZIP）
