# Cursor セットアップハンズオン

公開勉強会向けの **60分** 資料です。Cursor 未経験の参加者が、公式サイトからのダウンロード、プランの適用、小さい修正まで進めます。

手順の本文は各章にあります。このページは入口だけです。Cursor を入れる前でも、ブラウザでこの README を開いて進めてください。

## 対象

- エディタを開いたことがある人
- Cursor は初めて、またはほとんど使っていない人

プログラミング超入門ではありません。

## 学習目標

1. Cursor を公式サイトから入れてサインインできる
2. 料金ページの違いが分かり、当日配布のクレジットでプランを付けられる
3. Ask でコードを説明させ、Agent で小さい変更を入れて diff を確認できる

## 当日の流れ（60分）


| 分     | 章                                          | やること                                  |
| ----- | ------------------------------------------ | ------------------------------------- |
| 0–5   | この README                                  | ゴール共有。すでに Cursor がある人は DL を飛ばしてサインインへ |
| 5–20  | [00 ダウンロード](docs/00-download.md)           | 公式サイトから入れて起動し、サインインする                 |
| 20–30 | [01 プラン](docs/01-plan.md)                  | 料金ページを見て、必要なプランを契約する（任意）            |
| 30–40 | [02 初回起動](docs/02-first-launch.md)         | このフォルダを開く。画面と Agent の場所               |
| 40–60 | [03 Ask と Agent](docs/03-ask-and-agent.md) | 説明させる → ボタンを直す → diff を確認             |


画面の名前やボタン位置は Cursor のバージョンで変わることがあります。見つからなければ進行役に声をかけてください。
